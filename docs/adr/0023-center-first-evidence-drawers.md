# Center-first evidence canvas with parallel context drawers

Status: accepted

LangReport’s workbench keeps the Evidence canvas as the default reading surface and treats conversation history and project context as independent drawers that may remain open together. On wide screens the drawers occupy their own grid tracks, the context drawer is resizable from 300–560px for lineage and field content, and Snapshot preview replaces the context drawer in place; closing that preview closes the context drawer. This preserves evidence readability while keeping audit material close at hand, and avoids turning a data preview into a full-screen modal or a second page-level navigation system.

Considered alternatives: mutually exclusive drawers, a permanently pinned three-column layout, and a full-screen Snapshot modal. The chosen shape keeps the center canvas usable, supports simultaneous comparison, and makes the preview’s relationship to project context explicit.
