# 个人偏好私有隔离，并区分个人与项目记忆的删除留存

用户已确认本设计决策；实施授权和范围见活动变更记录。个人偏好只属于认证用户，采用独立存储、私有 Cycle 上下文和使用记录。共享 Project/Job/Revision/审计/日志不包含其正文、key、ID、hash、私有 fingerprint 或使用标记；图表视觉默认仍由 Project Visual Template 管理。

把偏好混入 Workspace/Project 表与公共 DTO 虽然复用更多代码，却把一次漏过滤变成泄露；因此选择物理与合同隔离，内部复用 Memory 规则和 Adapter。模型提议需确认，明确、非引用的“记住”且 scope 清楚时可直接确认。

删除优先于版本冻结：删除成功后所有后续调用排除逻辑记忆及旧版本，撤销覆盖缓存与派生摘要。个人偏好清除记忆存储内当前/历史正文与派生副本，仅留 owner-only 无正文删除元数据；Project 逻辑删除后历史仅授权审计可读。原始 Conversation、报告独立留存，界面说明范围；不承诺撤回已发出的请求或结果。

代价是删除依赖追踪、来源抑制、并发发送门和备份恢复重放；不能以可复现为由保留已删个人正文，也不能用旧对话提取或回滚让其复活。详细约束与验收见 [记忆设计](../changes/2026-09-24-memory-system/design.md)。备份恢复账本、失败关闭和保留边界由用户于 2026-09-27 进一步批准，具体实现约束见 [ADR-0029](./0029-memory-revocation-ledger-and-recovery-gate.md)。
