| ID  | 场景                                                             | 验收                                                                                    |
| --- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| P1  | CSV/XLSX/JSON/paste 与原纯函数同输入                             | normalized 全部行、类型、列映射、警告、画像、preview 深比较相等                         |
| P2  | 100k×20，预热五轮；高基数 10k/20k/40k                            | 解析中位≤5秒，额外峰值≤512MiB，40k/10k≤6；逐次保留数据                                  |
| P3  | 真实上传及更新同时请求健康/授权只读接口                          | 各五轮固定负载，p95 相对空闲增加≤200ms，HTTP 错误另计，包含序列化、S3、DB；探针不能替代 |
| P4  | 两个并发上传、慢上传、连续失败                                   | 单槽繁忙错误正确，无无界队列；结束/断开后下一次可成功                                   |
| P5  | 超时、崩溃、无消息退出、异常消息、取消竞争、服务关闭             | 只完成一次，线程已退出，临时文件清理，无同步回退/自动重试                               |
| P6  | 50MiB/100万行/200列边界、压缩 Excel、超大单元格、输出/元信息上限 | 隔离测试进程监控资源并设总超时；明确失败且 API 存活，不在现用服务压测                   |
| P7  | S3/DB 失败及 COMMIT 结果未知                                     | 不删除可能已提交对象、不发布半成品、不错误覆盖旧 Snapshot；不能证明则阻塞               |
| P8  | local/lark/provider JSON、开发/发布入口                          | 路由和成功状态兼容，无额外飞书调用，无生产依赖实验 loader                               |
| P9  | 错误合同与 UI                                                    | OpenAPI/Console 同步，桌面/移动显示繁忙、超时、资源错误，正常上传不退化                 |

测量记录 Node/硬件、输入生成方式与哈希、预热和各轮原始值、父线程序列化/复制耗时、总 RSS、采样方法。基线请求完成后再进入压力阶段，避免阶段跨越污染；HTTP 客户端独立于被测线程。所有失败、非 200 和超时都计入结果，不能只统计成功请求。验证退出应自然结束，不用 force-exit 掩盖资源泄漏。测试新增后纳入 package scripts 的实际发现范围。

独立验证使用实现后的只读完整快照，覆盖 P1–P9；无业务代码实现时不声明这些场景已通过。
