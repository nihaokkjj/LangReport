# T6 候选输出清单限定独立复核

- 日期：2026-10-07
- 范围：冻结快照 `t6-manifest-review-fixed` 中的 Render Worker、数据库迁移及 Worker 集成断言
- 方法：独立角色只读检查固定源码快照；没有修改产品工作树，也没有独立运行 PostgreSQL/MinIO 集成测试

初次复核发现恢复已有 Revision 时，旧 PNG/SVG/Vega 对象若被改写，代码会按改写后的字节重算哈希并保存为新的清单，无法发现旧清单与对象不一致。owner 修正为：已有清单时，恢复必须逐项核对旧对象的 key、SHA-256 和字节数；不一致时报 `RENDER_OUTPUT_MISMATCH`，Job 仍使用可重试的 `RENDER_FAILED`。同时增加真实 MinIO 的 PNG 篡改回归，断言恢复失败且原候选清单不变。

独立角色对最终固定快照完成限定只读复核，确认上述 P2 已修正，未发现新的 P1/P2。此结论仅覆盖所查源码和测试断言，不代表独立集成执行。历史上没有清单的 Revision 恢复只记录对象可读，无法追溯验证旧内容。
