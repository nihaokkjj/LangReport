# T6 候选对象账本独立只读复核

- 日期：2026-10-07
- 范围：本轮 `0034` 迁移、账本/Render Worker/发布事务及真实集成断言的只读审查；未改产品代码，未独立重跑集成。
- 首轮发现：对账年龄与租约使用 Worker 进程时间，可能早于数据库有效期清理；单条 S3 DELETE 持续失败会阻断后续候选；活跃租约断言的候选未明确老化。
- 修正复核：预筛和锁内以 PostgreSQL `clock_timestamp()` 判断年龄与租约；失败尝试 `deleting` 保留并延迟一分钟重试，单项失败不阻断本批其他项；无效键隔离、已引用键保护。测试显式老化有效租约尝试。发布和对账遵守 Job→attempt 锁序，发布事务只接受 `validated` 并原子标为 `published`。
- 结论：最新静态快照未发现新增确定性 P1/P2。此结论不代替 owner 的完整集成运行或 T6 整体验收。
