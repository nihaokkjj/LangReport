# 数据库账号管理：Proposal

- 变更编号：CHG-2026-09-26-database-user-accounts
- 状态：APPROVED
- 创建时间：2026-09-26
- 更新时间：2026-09-26

## 背景

当前登录网关使用部署环境变量配置一个登录身份和 scrypt 密码哈希。认证用户 ID 直接进入 JWT subject，并通过现有的 Workspace Member、Project Member 关系读取私有项目。系统没有数据库用户表，也没有账号停用、数据库密码更新或 CLI 账号生命周期管理。

用户已确认把账号身份和密码哈希存入数据库，并采用 CLI 管理其他账号。此变更扩展现有登录网关；它不会把 Workspace 暴露成用户管理概念。

## 要解决的问题

单一环境变量身份无法分别创建、停用或重置多个账号，也不能让用户自行修改密码。现有项目数据需要继续归属到迁移后的首个数据库账号，同时保留已经签发的旧会话直到原始过期时间。

## 目标用户与使用场景

- 部署维护者：在首次启动时由部署配置引导创建首个普通用户；之后通过服务器 CLI 管理账号。
- 咨询顾问：用用户名和密码登录，查看自己的 Project，并在账号页自行修改密码。
- 维护人员：停用或重新启用账号、重置密码，同时保留该用户的 Workspace 和项目数据。

## 需求范围

### MVP

1. 在数据库增加 users 表，保存身份、规范化用户名、scrypt 密码哈希、账号状态和必要时间字段。
2. 用户名去除首尾空格后按大小写不敏感方式查找，并要求规范化用户名唯一。
3. 应用仅在 users 表没有记录时，从显式部署配置幂等创建首个普通账号；已有账号时不得被环境变量覆盖、重置或重新启用。
4. CLI 提供账号创建、查询、停用、重新启用和密码重置；不新增应用管理员角色或网页管理后台。
5. 登录改为验证数据库账号。用户可在账号页修改自己的密码，必须提供当前密码。
6. 用户自设密码最低 6 个字符；不强制首登改密或定期更换。账号创建和 CLI 重置使用同一部署密钥配置的共享密码，该密码至少 15 个字符且随机生成；用户自行改密只影响自己的账号。
7. 账号停用保留用户行和 Workspace/Project 数据；停用、管理员重置密码或用户自助改密都不撤销现有 JWT，各会话保留到自己的原过期时间，最多 7 天。
8. 把旧 AUTH_LOGIN_USER_ID 对应的 Workspace 与 Project 成员关联迁移到首个数据库用户，保留业务数据 ID；旧 JWT 通过临时身份映射在原有效期内继续访问，映射最多 7 天。
9. 迁移现有 auth API、API Contracts、OpenAPI、API Console、部署配置和相关文档；新增用户账号页。
10. 应用不执行登录失败次数限制；生产登录入口必须由 Nginx 或 WAF 限速，并禁止绕过入口直接访问 API。
11. 不为账号创建、停用、启用或密码重置写入账号管理审计记录。

### 后续范围

- 角色或权限层级、网页管理员界面、用户注册和邀请。
- 邮件验证、邮件密码找回、多因子认证、企业 SSO/OIDC。
- 服务端 Session 存储、单设备撤销和密码变更后的主动登出。
- 账号管理审计、组织/团队成员协作、跨 Workspace 管理。

## 明确不做

- 不把 Workspace 当作用户可见的账户或团队对象。
- 不删除停用用户或其历史 Project、Revision、审计来源和对象存储内容。
- 不在数据库或日志中保存明文密码、共享密码、JWT 或 Cookie。
- 不导入旧环境变量登录账号作为数据库账号；创建新的数据库身份并迁移访问关联。
- 不在本变更中重构咨询报告生成、审核、导出或 Worker 数据流。
- 不将未经真实 HTTPS 环境验证的 Cookie 行为标记为已验收。

## 成功指标

- 首次启动后数据库只有一个由配置引导的普通账号；重复启动不修改账号密码或状态。
- 两个账号可分别登录；用户名大小写和首尾空格变化仍解析到同一身份，规范化后重复账号无法创建。
- 用户可使用当前密码自行设置至少 6 字符的新密码；错误当前密码和错误新密码被拒绝。
- CLI 创建、停用、启用和重置操作只影响指定账号；停用账号按选定策略保留现有会话。
- 旧 Workspace、Project 和成员授权关联迁移到首个数据库账号，业务数据 ID 和历史操作来源不变。
- 账号隔离、数据库迁移、登录 Cookie、入口限速、账户页和 CLI 行为都有可复现的验证记录。

## 假设、依赖与风险

- 生产 API 只能从实施登录限速的 Nginx/WAF 入口访问；应用本身不负责登录限速。
- 当前登录会话最长 7 天。停用、管理员重置密码或用户自助改密后，旧会话仍可使用至各自过期，故这些操作都不是即时会话撤销。
- 用户自设 6 字符下限低于 NIST 对单因素密码的 15 字符基线。共享初始/重置密码虽要求至少 15 个随机字符，用户仍可改成 6 字符密码。
- 一个共享初始/重置密码可能长期留在多个未自行修改的账号上。密码泄漏会扩大受影响账号范围。
- 旧身份映射仅兼容迁移前尚未过期的 JWT，不延长 token 的 exp；生产迁移前必须备份数据库。
- 旧登录网关变更记录保留其已实施实现和 PARTIAL 验收结论；本变更另行记录数据库账号方案及对应用内失败窗口的调整。

## 文档评审状态

## 验收标准概要

1. users 表、唯一用户名约束和可回滚的版本化迁移经过数据库迁移检查。
2. 启动引导只在用户表为空时生效，账号创建和数据关联迁移处于同一幂等事务。
3. 登录使用数据库账号；无效、停用和不存在账号返回同一凭据错误。
4. 账号页改密要求验证当前密码；所有用户自设新密码至少 6 个字符。
5. CLI 支持创建、列表、停用、启用、重置；共享密钥不在参数、输出、日志或数据库明文中出现。
6. 旧认证 subject 映射不延长 JWT 有效期；迁移后的 Workspace、Project 权限与数据归属符合需求。
7. API 进程无登录失败计数；生产反向代理/WAF 对登录入口限速且 API 端口不能绕过代理公开访问。
8. Web、Contracts、OpenAPI、API Console、Compose、环境示例和运维文档与实现一致。
