## 测试范围

覆盖 CLI 固定协议、Data Intake Job 状态与租约、Snapshot 唯一发布、审计脱敏、API/Web 状态、旧数据兼容。离线和隔离集成测试禁止调用真实飞书、真实模型或生产数据；真实飞书只用合成样例并单独记录。

| 风险 | 场景 | 预期结果 |
| --- | --- | --- |
| 重复云表 | 导入返回 `ready=false/ticket`，随后两次 pending、一次 ready | `+workbook-import` 仅一次，续查三次 |
| 中断后重放 | 导入前、导入后落库前、ticket 落库后、读取中、提交响应丢失分别中断 | 无引用时结果未知并停；有引用时只读续查；最多一个 Snapshot |
| 旧任务误恢复 | 迁移已有 failed/pending ticket 记录 | 不自动排队或重导入，保留原状态与引用 |
| 伪造或越权 | 错误 Project/用户/open_id，客户端构造 ticket/token | 在工具调用前拒绝，不泄露恢复引用 |
| 表格变化/截断 | 续查后 revision 改变、范围不符、输出截断 | 不发布 Snapshot，保留原因 |
| 审计泄露 | CLI 错误含 token、原始单元格或 stderr 敏感内容 | 公共状态与结构化审计均不包含原文；内部引用只在受限字段 |
| 审计成本 | 多次 pending 与大范围读取 | 调用次数、耗时、token 汇总正确且体积受限 |
| 前端等待 | awaiting_import、成功、明确失败、结果未知 | 状态文案准确；关闭页面不取消后台任务 |

## 验证与证据

先保存修复前复现，再运行 lark-data/Worker 单元、隔离 API/Worker 集成、合同与 Web 测试、类型和迁移检查。独立验证使用固定代码快照，记录实际命令、退出码、失败项和修复后复测。真实飞书合成样例只验证一个小型导入与续查协议；不能替代多用户、复杂公式或大表验收。
